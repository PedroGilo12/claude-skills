# c-noframework

Mini-projeto C puro (nem Zephyr nem ESP-IDF), **sem nenhum framework de teste unitário**.
Escrito para o eval de "parar e perguntar" da `embedded-unit-testing` (Caminho C, Fase 0):
diante de `src/debounce.c`, a skill deve perguntar qual framework usar em vez de assumir um.

Não adicione testes, `test/` nem dependências de framework aqui: isso invalida o eval.
